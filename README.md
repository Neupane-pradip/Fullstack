# HTML, CSS, and JavaScript Practice

A collection of introductory web development exercises, organized by topic. Each exercise is a separate page rather than part of one application.

## Explore the exercises

| Folder | Focus |
|---|---|
| [01_html](01_html/) | HTML page structure and markup |
| [02_css](02_css/) | Stylesheets and page presentation |
| [03_javascript](03_javascript/) | DOM manipulation, browser events, dice, and contact-data exercises |

Start with [01_html/ex3/index.html](01_html/ex3/index.html), then browse the CSS and JavaScript folders.

## View locally

Clone the repository and open an exercise's `index.html` in a browser:

```sh
git clone https://github.com/Neupane-pradip/Fullstack.git
cd Fullstack
```

For a local web server, Python 3 is sufficient:

```sh
python -m http.server 8000
```

Visit `http://localhost:8000` and select an exercise. Stop the server with Ctrl+C. No npm build step is configured in this repository.

## Project status

This is a coursework snapshot containing exercise material and practice code. Some folders are placeholders, and some pages reference scripts that are absent; the collection should not be treated as a finished web application.

The contact exercise includes supplied static user data. It does not fetch a live user API.
